### Orchestration shape (mocked vs. live)
- Everything in the `Cala → OpenAI → Fal` chain is **100% mocked**. There is no live network call to Cala's MCP endpoint, OpenAI, or Fal.ai anywhere in `frontend/`.
- The only genuinely "live"/real I/O in the frontend pipeline is local filesystem writes: the mock Fal client writes real SVG files to `frontend/public/moments/spain/`, and `generate.ts` writes the real `frontend/data/spain.json`.
- The real Cala integration exists only in the separate, unrelated `backend/knowledge_search.py`, which does call the live Cala MCP endpoint (`https://api.cala.ai/mcp/`, tool `knowledge_search`) over raw JSON-RPC/HTTP with `CALA_API_KEY`, handling both SSE and plain-JSON response bodies. It resolves citation titles via a provenance chain (`explainability[i].references → context[j].id → origins[k].document.name`, falling back to publisher name) and extracts a `timeline` via regex. This script is standalone — its output (`data/knowledge-search.json`) is not consumed by `generate.ts` or the frontend at all today.

### Hardcoded vs. parameterized
Hardcoded in `generate.ts`: country code (`"ESP"`), era bounds (`1492`/`1588`), country name (`"Spain"`), era label/rationale prose, output image folder (`moments/spain/`), output JSON filename (`data/spain.json`). Hardcoded in `cala.ts`: the entire fact set (ignores its own function parameters). Hardcoded in `fal.ts`: the placeholder SVG art direction (gradient colors, layout) — no actual "style reference" mechanism exists yet (no `styleProfile` usage despite the type field existing). Parameterized/dynamic in shape only: the `Country`/`Moment` TypeScript types themselves are country-agnostic and index/id-driven, and the per-moment loop (`facts.map`) is structurally generic — but nothing currently drives it with variable input since every adapter is a mock ignoring its arguments. In short: the *interfaces* (`CalaClient`, `OpenAIClient`, `FalClient`, `Country`, `Moment`) are designed to be swapped for live implementations and multiple countries, but today every concrete value is a Spain/1492–1588-specific literal baked into `generate.ts` and the three mock adapters.</result>
